# 2026-09 Hello-Agents 进阶学习

每天90—120分钟，围绕“预测→实践→观察→解释→验证”学习。主要输出学习笔记和自己的思考，不录制视频。

当前阶段：学习准备。Task00—Task07均为待学习模板，不能据此认定课程已完成。

## 从这里开始

1. 阅读[怎么学习](怎么学习.md)，明确时间安排与陪学方式。
2. 按下面日期打开对应任务，先回答第一个引导问题。
3. 在任务页记录真实实践和思考；需要时使用[完整笔记模板](学习思考笔记模板.md)。
4. 用[闪卡](学习资源/闪卡.md)复习，用[测验题](学习资源/测验题.md)检查理解。
5. 参考[NotebookLM学习指南](学习资源/NotebookLM学习指南.md)；具体日程与范围以本页为准。

## NotebookLM与GitHub怎样配合

- [本期NotebookLM笔记本](https://notebooklm.google.com/notebook/3880b09d-cd9d-4f19-b4cc-567bae9966cc)：存放任务分组教材、配套代码参考和学习约束，用于基于资料的生成与追问；访问受Google账户权限限制。
- 本GitHub目录：保存学习方法、任务笔记模板、导出的学习指南、闪卡和测验，便于复习与持续更新。
- 个人思考来自自己的回答，AI负责逐步提问和整理，不虚构心得或运行成果。
- 本地 `hello-agents/` 是教材源码参考，已配置目录级忽略规则，不上传到博客仓库。NotebookLM导入的是本期任务范围内的文本资料包，不是整个项目的所有文件。
- 生成来源、资料范围与核对说明见[资料与生成记录](资料与生成记录.md)。补充题库不是官方作业或考试题。
