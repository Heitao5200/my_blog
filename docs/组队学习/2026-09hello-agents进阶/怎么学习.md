# 怎么学习：每天90—120分钟

本期按任务截止日期推进，不录制视频。学习产出为笔记、自己的思考，以及任务要求的实践证据。每天时长包含测验和整理，不额外加时。

## 每天的时间分配

| 环节 | 常规 | 有余力时 | 做什么 |
| --- | ---: | ---: | --- |
| 回顾 | 5分钟 | 5分钟 | 回答昨天的一张闪卡，确定今天的问题 |
| 阅读 | 25分钟 | 35分钟 | 读任务指定小节，带着问题找解释 |
| 实践 | 40分钟 | 60分钟 | 跑示例、改一个变量、做习题或小测 |
| 笔记与思考 | 20分钟 | 20分钟 | 记录证据，回答引导问题，写未解疑问 |
| 合计 | 90分钟 | 120分钟 | 到点收尾 |

小测用实践环节的5—10分钟；闪卡用回顾时间。教材习题按组队要求完成，本站补充题不冒充官方习题。当天来不及就减少补充题和扩展功能。

## 让AI引导思考，而不是直接给总结

每次只问一个问题，按你的回答推进：

1. **先预测**：运行前猜会发生什么，并说一句理由。猜错没关系。
2. **再观察**：找一次工具调用、一条报错、一个检索片段等具体证据。
3. **比较差异**：哪里与预测不同？不要用“跑通了”代替观察。
4. **尝试解释**：说出可能原因，区分已验证事实和猜测。
5. **小实验验证**：只改变一个条件，观察解释是否成立。
6. **表达自己的认识**：记录判断改变了什么，还有什么不知道。

答不上来时，AI先给观察方向，再给一个提示或更小的问题；仍有困难再解释，并让你换个例子复述。不一次倾倒所有问题和答案。

## 可以直接交给AI的陪学指令

> 我正在学Hello-Agents的TaskXX，今天有90—120分钟。请根据本任务教材和我的实际进度带我学习。每次只问一个问题，先让我预测，再让我提供运行或阅读证据，再追问原因和验证方法。答不上来时逐级提示，不立即公布答案。最后根据我的真实回答整理笔记，未回答的部分保留“待思考”，不能替我编造实践经历或心得。闪卡和小测计入当天时间，不增加任务量。

## 时间不够时

- 90分钟检查剩余必做项，最多延长到120分钟。
- 同一报错超过20分钟，记录错误、已尝试的方法和环境信息，带着证据求助。
- 优先教材指定实践和任务交付；高级检索、额外工具、多项目同时运行均为选做。
- 多日任务每天写短记录，最后一天合并，不重复写一篇长教程。
- 未跑通就记录真实失败和下一步，不填写成功截图或“已掌握”。

## 闪卡、小测与复习

先回忆后翻答案；每次只选已学任务的3—5张闪卡或2—3道题。错题写一句“我把什么混淆了”，第二天先重答一题。开放题不要求背标准措辞，要解释原因并给出证据或验证方案。
