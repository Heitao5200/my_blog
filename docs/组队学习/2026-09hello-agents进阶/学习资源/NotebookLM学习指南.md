# NotebookLM学习指南（核对整理版）

本指南由NotebookLM依据本期9组资料生成初稿，再对照教材、任务截图和用户学习约束进行修订。具体日期以[学习总览](../README.md)为准。个人认识由你回答形成，本页不代表完成学习。

每天：5分钟回顾＋25—35分钟阅读＋40—60分钟实践＋20分钟笔记＝90—120分钟。下述实践占用当天实践时间，不另外增加90或120分钟。每次只问一个问题；开放题解析先折叠。

## 如何使用参考分析

以上16道情境题由NotebookLM初稿的主题扩展并经编辑整理，不是官方习题。允许不同的合理答案；判断标准是有没有抓住问题、引用证据、提出可验证的方法。一次只选一题，计入当天学习时间。
